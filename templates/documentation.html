Common Scenarios & Step-by-Step Guide

  1. Choose Standard Invoice from the Invoice Type dropdown.
  2. Fill in all required fields (marked with a red asterisk).
  3. Upload your first receipt/invoice file.
  4. To add more pages, click Add Page and upload additional files. Each page must have a file selected.
  5. Click Submit Expense. Any missing or invalid fields will be highlighted in red with an error message.
  6. After successful submission, you will see a confirmation and can view your record in the EPV Records page.

  1. Choose Split Invoice from the Invoice Type dropdown.
  2. Fill in the master invoice details and upload all pages for the main invoice (all files will be merged).
  3. Click Add Allocation to add cost center allocations. For each allocation, fill in the cost center, amount, expense head, and approver email.
  4. Ensure the total allocated amount matches the master invoice amount (the system will warn you if not).
  5. Click Submit Expense. All required fields and missing files will be highlighted in red if incomplete.
  6. After submission, approval emails will be sent to the specified approvers for each allocation.

  • To add more pages to any expense, click Add Page in that expense section.
  • Each page must have a file selected. If you try to submit without a file, the field will be highlighted in red.
  • To remove a page, click the red X next to the file input (only available if more than one page exists).

  • All required fields are marked with a * (red asterisk).
  • If a field is missing or invalid, it will be highlighted in red and an error message will appear below it.
  • For file uploads, every page must have a file selected. Missing files will be highlighted in red.
  • The form will scroll to the first error automatically when you try to submit.

  • For standard invoices, your expense will be submitted for approval as per your organization's workflow.
  • For split invoices, approval emails will be sent to the approvers you specified for each allocation.
  • You can track the status of your submission in the EPV Records page.
  • If there are any issues, you will see error messages and can correct them before resubmitting.
